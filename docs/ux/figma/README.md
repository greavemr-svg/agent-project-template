# Figma exports (fallback)

If the Figma connector isn't available, export each frame from Figma
(select frame → Export → PNG @2x) and save it here as `<screen-id>-<name>.png`,
for example `S1-walk-check.png`. The UX designer reads these as images.

Exact colours and spacing are then estimates; with the Figma connector they're
read exactly.
